# Glossary

- **Scenario**: Workflow definition represented as data (YAML/JSON).
- **Step**: Single unit of execution in a scenario (for example: send, verify, or lifecycle hook).
- **Plugin**: Swappable implementation used by steps (transport, verify, or lifecycle behaviors).
- **Evidence**: Artifacts that prove what happened during a run.
- **Run ID**: Unique identifier for a single scenario execution.
