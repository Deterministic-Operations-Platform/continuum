# v0.3 Finish-line status

## Current `bundle_signature.json` schema
Generated by `continuum.signing.sign_manifest_hmac`:

- `algorithm` (string) — currently `HMAC-SHA256(manifest_sha256)`
- `manifest_sha256` (string)
- `signature` (string, hex HMAC)
- `createdAt` (string, UTC timestamp)
- `keyId` (string)

## Redaction / evidence safety guardrails

- Publish redaction explicitly skips:
  - `manifest.json`
  - `bundle_signature.json`
  - `manifest.sha256`
- Jira publish evidence payload includes run metadata and signature metadata, but not auth credentials.

## v0.4 target (requested)

- Add Ed25519 keypair support (`continuum keygen`, public-key verification path)
- Extend signature payload with `publicKeyId`
- Support verify using only public key
- Add evidence vault upload plugin + `evidence_vault.json`
- Update viewer status from "Signed" to "Verified" when cryptographic verification succeeds
